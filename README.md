# Death Arena Apocalypse

Top-down roguelite arena game. Five clans (Biopunk, Steampunk, Solarpunk, Cyberpunk, Voidpunk), 25 heroes with mix-and-match loadouts and per-hero skill trees, a big connected world per act with no map, risk rooms, altar trades and exit-or-descend after each boss.

Static site, no build: open `index.html`.

Controls: WASD move, mouse aim + hold to attack, Space dash, Q hero ability, F auto-fire, P / Backspace pause.
